About AI Travel Planner

This project is designed as a modern, premium AI-powered web application for an AIML internship demonstration.

It leverages the power of Google's Gemini API to generate customized, highly detailed day-by-day itineraries based on user preferences, budget, and travel style.

Technologies Used:

  • Frontend: HTML5, CSS3 (Glassmorphism, Animations)
  • Backend: Python, Flask
  • Database: SQLite
  • AI: Google Gemini API
